iData & methodology+

Who is included?

The cohort uses the published current leaderboard snapshot. “Both teams” requires both sides in its selected top N. “At least one” includes the match, then counts only observations from qualifying current top N teams. Historical match-start ranks do not determine inclusion. Queue, map and team filters narrow the cohort.

Current leaderboard snapshot details will appear when data loads.

Teams absent from the published current leaderboard are excluded. The leaderboard snapshot can change between builds. A team’s current rank is separate from its historical Elo changes shown in champion statistics.

What do the rates mean?

Champion performance always includes all qualifying wins and losses. Choosing a champion changes the item and build sample. The outcome switch applies only to items, consumables and builds.

Item rates count champion appearances with at least one purchase, final held copy or closing purchase. Closing buys occur in the final 10% of a match’s rounds. Rates use the displayed champion appearance denominator. Final builds use official end-of-match inventories. Emblems automatically combine from 5 shards; only shards can be bought.

Elo gained sums actual team series Elo changes divided by the official number of maps in that series, per champion appearance. Every drafted champion shares the team movement; this is not causal credit. Unknown or unranked Elo is omitted, and the rated appearance count shows coverage. Net wins is wins minus losses.

Teammate pairs count once per qualifying side; a repeated champion type does not duplicate a pair. Lift is pair win rate minus the average of the two champions’ baseline win rates. Opponent matchups show the named champion’s win rate against each enemy champion, using both outcomes. Their expected rate averages its baseline and 100% minus the opponent’s baseline; missing baselines show no lift. These are correlations across team compositions, maps and repeated opponents.

Choose “By map” to compare champion, item and team win rates across the selected maps. Each cell shows wins / appearances from both outcomes. The minimum applies separately to every map and category; a dash marks a sample below the minimum or no appearances. Champion selection narrows item samples, and team selection narrows all samples. Select a map heading to focus on that map.

Each map counts as one match. Repeated maps from the same series are correlated, so apparent differences may reflect a small number of team pairings. Rates are descriptive.

How fresh is the data?

GitHub Actions requests an archive update every 5 minutes. Scheduled runs can be delayed or skipped, and publication takes additional time. This page checks the published snapshot every 5 minutes; “Check for updates” reloads that snapshot. It does not start a collector run. Previous valid data remains available if a check fails.

The coverage panel shows the requested time window, actual published match range, current leaderboard snapshot and dataset build time separately. Collection is capped per team, so the sample does not include every game in the requested window. An archive uploaded or a dataset built today can still contain older matches; use match timestamps to judge freshness.
